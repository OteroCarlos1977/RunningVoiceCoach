# RunningVoiceCoach — Fase 09 — ActiveRunScreen definitiva para MVP

Este documento corresponde a una fase independiente para trabajar en Codex.

**Regla general:** no avanzar a la fase siguiente hasta que esta compile, funcione y cumpla sus criterios de aceptación.

---

## Objetivo

Mejorar la pantalla activa para visualizar claramente los datos de la carrera y el bloque actual.

---

## Tareas de esta fase

- Mostrar tiempo total.
- Mostrar distancia total.
- Mostrar ritmo actual.
- Mostrar ritmo promedio.
- Mostrar bloque actual.
- Mostrar ritmo objetivo.
- Mostrar progreso del bloque.
- Mostrar diferencia respecto del objetivo.
- Agregar botones iniciar, pausar, reanudar y finalizar.

---

## Prompt para Codex

```text
Mejora ActiveRunScreen.

Debe mostrar en grande:
- tiempo total
- distancia total
- ritmo actual
- ritmo promedio
- bloque actual
- ritmo objetivo
- progreso del bloque
- diferencia respecto del objetivo

Debe tener botones:
- iniciar
- pausar
- reanudar
- finalizar

Debe funcionar primero con el simulador de carrera.

La UI debe ser clara para verse rápido durante una actividad física.
Usá textos grandes, buen espaciado y pocos elementos en pantalla.
```

---

## Criterios de aceptación

- Los datos principales se ven claramente.
- Los botones funcionan con el simulador.
- La pantalla no está saturada.
- El estado de carrera se mantiene al navegar dentro de la app.
